## HEX 2.0.16

- Finds OpenCode beta installations from common macOS package-manager
  locations without requiring a `launchctl` environment override.
- Isolates OpenCode requests in HEX's Application Support directory instead of
  allowing them to initialize against the home directory or filesystem root.
- Shows HEX in the Dock by default, activates its window reliably, and keeps
  the selected command visible while navigating the Commands pane.
- Speeds up foreground application and window context capture with native
  macOS APIs.
