## Hex 2.1.22

- Avoids launching an unnecessary AppleScript process when Pause Media is
  selected and no supported media player is running.
- Simplifies Settings navigation and processing-model catalog handling while
  preserving the available panes, model choices, and defaults.
- Reduces repeated allocation when refreshing developer-only live meeting
  transcripts.

This macOS maintenance release uses build 20122. The public TypeScript SDK
remains at 0.3.0. No Linux binary is published with this release.
