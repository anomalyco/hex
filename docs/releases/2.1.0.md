## HEX 2.1.0

HEX now uses its new native Rust engine while keeping the established HEX
application identity. This is a major upgrade that replaces the original app in
place on supported Apple-silicon Macs running macOS 15 or newer.

- Dictation remains fully local and uses a new local transcription model that
  HEX downloads during setup.
- New installations default to NVIDIA Parakeet Unified English 0.6B. Existing
  explicitly selected transcription models remain unchanged.
- Your dictation and Paste Last shortcuts, recording audio behavior, microphone
  readiness, sound volume, and Dock preference are carried forward when
  possible.
- Existing Swift history, audio, models, and settings files remain untouched.
- Side-specific shortcuts, key-based double-tap dictation, configurable Paste
  Last, Voice Action, processing modes, text replacements, and text-only History
  are available in the native app.
- Personal commands now support typed digit, letter, choice, union, and trailing
  text captures, making natural command families possible without defining every
  spoken variation separately.
- Capture schemas reject ambiguous phrases, overlapping alternatives, malformed
  aliases, and invalid ranges before commands activate.
- Option-only dictation shortcuts no longer interfere with Finder's alternate
  menu items or other Option-click behavior.
- Synthesized keyboard shortcuts now preserve top-row number keys and balanced
  modifier transitions, and the recording HUD responds faster with a refined
  beam and glow.
- Local installs and upgrades handle missing or stopped older app bundles
  without aborting.

Intel Macs and Macs running macOS 14 remain on HEX 0.8.4.
