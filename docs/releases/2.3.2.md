## The new Hex is here

Rebuilt from the ground up, and it updates itself from now on.
Get it at [anoma.ly/hex](https://anoma.ly/hex).

- A new settings window and recording indicator
- Vocabulary: names and terms Hex spells right
- About 160 MB of memory instead of 900 MB
- New speech models, with accuracy shown in the picker
- No Input Monitoring permission

It's a new app: drag it to Applications and allow Microphone and
Accessibility again. It starts fresh, so you pick a speech model and your
shortcut once more, and it closes this Hex when it's ready.

This update only adds a link to the new Hex at the top of Hex's window.
This version won't get further updates.

This macOS release uses build 20302.
