## Hex 2.1.25

- Defaults Voice Action and OpenCode dictation rewriting to ranked fast,
  high-compliance models available in your OpenCode catalog (`gemini-3.1-flash-lite`
  with `minimal` thinking, `claude-haiku-4-5`, `gpt-5.4-nano` with `none`, and
  others in rank order), automatically falling back to the next available
  recommended model if an earlier one fails.
- Adds one-step model deletion with confirmation in the local speech model
  picker for non-active downloaded models.
- Refines the desktop interface, onboarding, and model picker to match the
  OpenCode V2 dark surface hierarchy with compact model cards, bordered
  controls, and single-line OpenCode model selectors.

This macOS release uses build 20125. The public TypeScript SDK remains at
0.3.1.
