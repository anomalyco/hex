## Hex 2.1.12

- Fixes a macOS crash when keyboard-layout lookups or initialization overlap
  across threads.
- Initializes the desktop keyboard map on the main thread before starting
  workers. Background lookups use that snapshot, including when a character
  is unavailable, instead of re-entering macOS keyboard-layout services.
- Preserves live keyboard-layout lookup for command-line use. The desktop
  keyboard map remains fixed until Hex restarts.
- Keeps dictation shortcut timing, double-tap locking, and Fn recovery
  behavior unchanged.

This macOS release uses build 20112. App identity, permissions, settings,
signing key, and the Rust update feed are unchanged. The public transcription
SDK remains at 0.3.0. No Linux binary is published, and the legacy Swift app
and feed are unchanged.
