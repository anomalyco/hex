## Hex 2.1.20

- Prevents managed-device executable policies from interrupting dictation when
  idle-sleep prevention begins.
- Uses a native macOS power assertion while intentionally recording instead of
  launching the `caffeinate` executable. If the assertion is unavailable, HEX
  logs a warning and continues recording.

This macOS release uses build 20120. The public TypeScript SDK remains at 0.3.0.
No Linux binary is published with this release.
