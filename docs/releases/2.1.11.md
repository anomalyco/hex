## Hex 2.1.11

- Fixes Option dictation remaining unresponsive after navigating or selecting
  text with arrow-key shortcuts. macOS can retain an incidental Fn flag after
  those keys are released; Hex now distinguishes that metadata from an actual
  held Fn modifier when recovering shortcut readiness.
- Recovers blocked modifier gestures even when no ordinary keys remain tracked,
  including after a missed release while ending a double-tap-locked recording.
- Delayed neutral releases no longer undo successful shortcut recovery and
  consume the next hold.
- Preserves double-tap timing, explicit Fn shortcuts, and held-key safeguards.
  Recovery never starts or finishes a recording by itself.

This macOS release uses build 20111. App identity, permissions, settings,
signing key, and the Rust update feed are unchanged. Temporary diagnostic
logging is not included. The public transcription SDK remains at 0.3.0.
No Linux binary is published, and the legacy Swift app and feed are unchanged.
