## Hex 2.1.13

- Fixes the sidebar Update button doing nothing when clicked. Its request now
  reaches the native updater instead of being lost during click handling.
- The button can reopen the update dialog after choosing Remind Me Later.
  The menu-bar Check for Updates command remains available as before.

This macOS release uses build 20113. Dictation, shortcut timing, app identity,
permissions, settings, signing key, and the Rust update feed are unchanged.
The public transcription SDK remains at 0.3.0. No Linux binary is published,
and the legacy Swift app and feed are unchanged.
