## Hex 2.1.14

- Application-specific Modes now match correctly when Finder shows `.app`
  extensions. Existing saved application selections are repaired automatically.
- Turning off **Show Dock icon** now lets HEX start quietly in the menu bar after
  setup. Setup or permission/model problems still open a window, and you can
  reopen HEX from the menu bar, Finder, or Spotlight.
- The Parakeet v3 model picker now explains that it detects language from audio,
  rather than using your selected language to guide recognition. For
  language-guided transcription, try Whisper. Existing selections are preserved;
  this clarification does not change Parakeet's recognition quality.

This macOS release uses build 20114. No additional startup setting is introduced.
The app identity, permissions, signing key, and Rust update feed are unchanged.
The public transcription SDK remains at 0.3.0. No Linux binary is published,
and the legacy Swift app and feed are unchanged.
