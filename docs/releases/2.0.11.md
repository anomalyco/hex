## HEX 2.0.11

- Adds TypeScript-configured personal voice commands with live status and
  lifecycle controls in Settings.
- Makes voice dictation start and stop phrases configurable.
- Improves voice-triggered speech onset, capitalization, control punctuation,
  and application-name matching.
- Adds explicit, environment-controlled diagnostic audio retention for
  investigating transcription failures. It is off by default and keeps only a
  bounded number of owner-only recordings.
- Expands the authenticated local transcription service and TypeScript client
  for host application integrations.
