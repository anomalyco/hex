## Hex 2.1.21

- Restores OpenCode-powered Modes and Voice Action with current OpenCode
  builds, which renamed both the service info route and the one-shot
  generation route. Older services keep working through the previous names.
- Keeps the microphone menu above the settings beneath it, so choosing a
  device no longer toggles another setting, and closes it when you click
  elsewhere. The recognition-hints editor no longer overlaps the shortcut row.
- Releases the audio output used for recording tones once dictation has been
  idle for five minutes, so an idle Mac can sleep again with sounds on.
- Pauses and resumes only media players that are already running instead of
  launching VLC to ask whether it is playing.
- Persists settings repairs at launch instead of re-applying them on every
  start, and keeps a shortcut capture open with an error instead of showing
  Saved when the settings file cannot be written.

This macOS release uses build 20121. The public TypeScript SDK remains at 0.3.0.
No Linux binary is published with this release.
