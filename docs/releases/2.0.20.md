## HEX 2.0.20

- New History pane (⌘5): successful dictations are retained locally as text —
  raw and final output, the app they pasted into, and timing — never audio.
  Search past dictations, copy or delete entries, clear everything, and pick a
  retention window from Off through Forever (default 7 days). Entries appear
  live while the pane is open.
- Personal command phrases can end in one `{name}` capture placeholder, such
  as `"search amazon for {query}"`. The spoken remainder arrives in the
  handler as `captures.name` (and on the Effect `Hex` service), so commands
  can search, open, or type with the captured words. Capture phrases require
  a handler, are bounded, and conflict with overlapping phrases at
  configuration time.
- The Commands pane is searchable: one field matches phrases, aliases,
  descriptions, and groups, replacing the old context filter chips.
- Voice Action no longer loses a capture when Command joins the shortcut
  slowly; the whole hold pastes through the Voice Action model as intended.
  Its settings use the same searchable model picker as Modes, and the timeout
  field is gone — processing now defaults to a 60-second deadline.
- Every pane shares one layout: a single content width, one header style with
  matching action buttons, and text that wraps instead of clipping. Commands
  sits before Voice Action, and ⌘1 through ⌘5 switch panes.
