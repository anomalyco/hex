## Hex 2.1.19

- Releases temporary transcription memory after each dictation instead of
  retaining the largest inference workspace for the lifetime of the app.
- Keeps the selected local model warm, preserving fast dictation startup while
  returning idle memory close to the model's baseline footprint.

This macOS release uses build 20119. The public TypeScript SDK remains at 0.3.0.
No Linux binary is published with this release.
