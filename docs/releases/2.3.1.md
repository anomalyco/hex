## Hex 2.3.1

- Plays the start sound as soon as you press the dictation shortcut, instead
  of after you've held it.
- Offers to record calls in Slack and other Chromium-based apps, whose audio
  runs in a helper process.
- Shows a small floating indicator while a meeting records, with Copy new and
  Copy all for the transcript so far.
- Keeps meeting recordings when the display sleeps: Hex finishes and
  transcribes the audio it captured instead of losing it.
- Adds a guided first run with a short practice dictation.
- Fixes a slow first dictation on Windows after installing or updating.
- Fixes Linux and Windows CI builds.

This macOS release uses build 20301.
