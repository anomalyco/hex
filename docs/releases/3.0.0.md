## Hex 3.0.0

### Upgrading from 2.3.1

Hex 3.0 starts fresh. It keeps its data in a folder named `hex` instead of
`voice-control` and imports nothing, so settings, History, meeting recordings,
and downloaded models start empty and the first launch downloads a speech
model again. Meeting notes already exported to `~/Documents/Hex Meetings` stay
where they are. The old `voice-control` folder is left alone, and you can
delete it.

2.3.1 doesn't update to 3.0 by itself. Download Hex from
https://anoma.ly/hex.

- macOS: Hex is now `anomaly.hex`, signed by Anomaly, so macOS treats it as a
  new app. Remove the old Hex entries in System Settings › Privacy & Security,
  then allow Microphone and Accessibility again. Turn Launch at login back on
  if you used it. Configuration profiles that set `DisableUpdates` need to
  target `anomaly.hex`.
- Windows: the installer is a new app in Settings › Apps, so installing 3.0
  leaves 2.3.1 installed. Uninstall the old Hex by hand.
- Linux: install again with the command on https://anoma.ly/hex.

### Removed

- Voice Action is gone.
- Spoken commands are gone, along with the Moonshine model they used.
  `hex.config.ts` now holds only transformations.

### New

- A new settings window, the same on macOS, Windows, and Linux. The sidebar
  has General, Output (replacements, per-app modes, OpenCode rewriting, and
  transformations), and History. Dev builds add Labs for Meetings, Annotate,
  and experiments.
- A new recording indicator on every OS.
- Vocabulary (Settings › General, or `hex vocabulary`): list names and terms,
  and Hex steers transcription toward them and fixes common mishearings.
- Shortcuts can use both Option keys together, a left or right modifier, or a
  mouse button.
- A new set of feedback sounds, with the old ones under Classic, and a picker
  you can listen to.
- On macOS, Hex can lower other audio to a volume you choose while you
  dictate, and pausing media now pauses the browser too.
- Local models use about 160 MB of memory instead of about 900 MB.
- New speech models, Underdog Bark 3.0 Pro and Clean, and Bangla. The picker
  shows each model's accuracy.
- Ukrainian interface language.
- Hex skips recordings with no speech in them instead of transcribing them.
- macOS no longer asks for Input Monitoring. Accessibility covers the
  shortcut.
- Meetings (Dev channel, in Labs) can remind you before calendar meetings once
  you connect a calendar, can always record calls from an app you choose, and
  finishes a meeting that was recording when Hex quit on the next launch.
- Annotate (Dev channel, macOS and Linux, in Labs) records the screen while you
  draw and talk, and sends it to an OpenCode session.
- The `hex` command controls the running app (`hex status`, `hex dictation`,
  `hex settings`, `hex meetings record`) and reads History and meetings
  (`hex history`, `hex meetings`, `hex mcp`).
- One updater on every OS, with a Stable or Dev update channel in Settings ›
  General.
- Linux gets ARM64 builds, `.deb` and `.rpm` packages, and a tray icon.

This macOS release uses build 30000.
