## Hex 3.2.0

### new

- a new first run on every os: hex sets itself up and downloads the speech model for your language, then you try it by answering a few practice messages with your shortcut
- if hex finds speech models already on your computer (in the hugging face cache), the first run lists them next to the recommended one in one simple list, so you can skip the download
- models: hebrew (ivrit.ai's whisper large v3 turbo) and nemotron 3.5 asr streaming 0.6b
- the interface speaks brazilian portuguese (português (brasil))
- the microphone is one switch beside the picker, and settings say what each microphone mode means for privacy
- speech engine has an auto / gpu / cpu setting, and hex remembers a gpu that hung so auto stays on the cpu for it

### fixes

- dictation no longer gets cut off after 2.5 seconds on mics that add a steady dc offset, like some built-in laptop mics (#841). 3.1.2 fixed this for quiet mics
- escape no longer cancels a dictation, so a stray key can't throw away what you said
- windows: dictations no longer pile up in clipboard history (win+v), and pasting works in remote desktop sessions
- linux: kde wayland hotkeys work when the portal starts before plasma, the shortcut recorder takes home, end, page up/down and arrows, the hyprland shortcut docs are current, and annotate records video on intel + nvidia laptops
- mac: the recording indicator lands in the right place on a second display, and gather calls get detected along with arc, meet and whatsapp
- long menus and pickers show that they scroll
- the homepage at https://anoma.ly/hex is faster
