## Hex 2.1.15

- Maintenance update that removes redundant shortcut and command-registration
  bookkeeping while preserving capture timing, configurable paste shortcuts,
  Voice Action ownership, and command matching.
- Simplifies settings input handling and HUD animation state without changing
  their appearance or controls. Adds regression coverage for command factories
  and Activity event identity, and verifies developer-only meeting shortcuts
  stay inactive in release builds.

This macOS release uses build 20115. No new features or settings are introduced.
The app identity, permissions, signing key, and Rust update feed are unchanged.
The public transcription SDK remains at 0.3.0. No Linux binary is published,
and the legacy Swift app and feed are unchanged.
