# Contributing to Hex

We don't take pull requests. [Open an issue](https://github.com/anomalyco/hex/issues/new/choose)
describing the bug or idea, and our agents usually turn it around fast.

Diagnoses and proposed fixes are welcome in the issue: redacted logs, the code
you suspect, or a patch as a diff snippet. If your analysis shapes the fix, we
credit you in the pull request that lands it.

To build Hex yourself, see [`AGENTS.md`](AGENTS.md) and [`docs/`](docs/README.md).
