## HEX 2.0.9

- Adds the Linux X11 dictation beta with user-local signed automatic updates.
- Links to the OpenCode beta install guide when OpenCode is missing.
- Adds voice editing for selected text with a configurable Option-Command shortcut.
- Revalidates the foreground app and exact selection before replacing anything.
- Uses a distinct green capture state so voice edits cannot be mistaken for dictation.
- Keeps a newer recording active when an older queued dictation finishes pasting.
- Preserves every clipboard item and format across dictation insertion.
